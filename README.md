# FIdo_TestTask2_University
# University Database

## Опис проєкту

База даних для обліку студентів, навчальних дисциплін і розподілу студентів за групами в межах дисциплін.

База даних містить три таблиці:
- `Students` — інформація про студентів.
- `Disciplines` — інформація про навчальні дисципліни.
- `StudentDisciplines` — зв'язки між студентами та дисциплінами, включно з номерами груп.

## Вимоги

Для роботи необхідно встановити:
- PostgreSQL.
- pgAdmin 4.

## Інструкція із запуску

### 1. Створення бази даних

1. Відкрийте pgAdmin 4.
2. Підключіться до сервера PostgreSQL.
3. У розділі **Databases** натисніть правою кнопкою миші.
4. Виберіть **Create → Database...**.
5. Введіть назву бази даних, наприклад `UniversityDB`, і натисніть **Save**.

### 2. Виконання SQL-скрипту

1. Виберіть створену базу даних `UniversityDB`.
2. Натисніть правою кнопкою миші та відкрийте **Query Tool**.
3. Відкрийте файл `university.sql` у редакторі або скопіюйте його вміст у Query Tool.
4. Натисніть **F5** або кнопку **Execute Script**.
5. Переконайтеся, що виконання команд завершилося без помилок.

SQL-скрипт створює таблиці, додає тестові дані та виконує запит для отримання студентів п'ятої групи дисципліни «Програмування».

## Структура бази даних

- `Students` — дані студентів: ПІБ, дата народження, email, телефон і рік вступу.
- `Disciplines` — назва дисципліни, опис, кількість кредитів і годин.
- `StudentDisciplines` — ідентифікатори студентів і дисциплін, а також номер групи.

Зв'язок між студентами та дисциплінами реалізовано через проміжну таблицю `StudentDisciplines`, оскільки один студент може відвідувати багато дисциплін, а одну дисципліну можуть відвідувати багато студентів.
